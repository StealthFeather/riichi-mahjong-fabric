# 26.3.25-replay.2：概率分析、实战弃牌标记与牌河侧回放控件

本版继续位于 `codex/mahjong-replay-analysis`，基于已部署的 replay.1 修改，不合并 main。

## 出牌和操作概率

弃牌数字改为策略概率百分比。现有麻将 AI 是确定策略，没有原生概率输出；本版从现有评估建立明确的 softmax 策略分布，保留高级 AI 的防守选择为最大概率。它不代表胜率或经过统计标定的玩家选择频率。具体公式、温度及推荐优先规则见 `ai/README.md`。

- 对全部合法弃牌牌种独立归一，整数百分比总和始终为 **100**；同一种牌的普通弃牌和立直弃牌合并为一种牌面选择，赤五与普通五分别计算。
- 吃、碰、杠、立直、和牌、跳过等全部合法操作另有独立的 100% 分布。桌沿复用实战的操作名称显示相应概率，立直按钮汇总全部合法立直弃牌的操作概率。
- 采用最大余数法分配整数显示，避免逐项四舍五入后合计不等于 100。单一选择可显示 100%，不再限制为 99。
- 手边每种弃牌选择显示一次概率；整数显示值低于 1% 的候选不显示数字。完整分布仍保留所有合法选项。
- 原来的“本局分数”现在是该玩家每次实际弃牌概率的平均值，HUD 显示“本局均值 X%”，不再当作决策质量评分。

分析缓存升级为版本 2，并标记策略 `modeled-softmax-v2`。数据库中的旧 0–99 分缓存不会继续显示，会在打开分析后重算；无需删除原牌谱或改表。

## 只标实际出牌的一个箭头

所选视角始终只有一个实战选择箭头：

- 实际选择达到最大策略概率：绿色。
- 实际选择排第二或第三：黄色。
- 其他选择：红色。

在出牌前的回放决策画面，箭头指向历史上实际选择的手牌；出牌后跟踪到准确的牌河位置。该牌被吃、碰、杠后，标记跟随原牌进入副露；加杠时不会误标新增的上层牌。红牌、相同牌的不同河牌序号均按记录身份区分。记录缺失、矛盾，或当次实际为暗杠、拔北、自摸时，不借用后续回合的弃牌冒充当前选择。

选择的实际概率显示在箭头上方，宽度与牌面一致。候选牌上仅显示概率，不再为前三候选各放一个箭头。

## 控件和上下巡

所有回放控件集中在所选视角牌河的左右空位，切换视角后一起移动，并朝该座位方向显示。两列共用实战按钮的文字、交互体和射线命中函数；布局避开牌河、牌山和四个座位的拔北牌。

左列为：开局、上一局、上一巡、上一步、播放/暂停、下一步、下一巡。

右列为：下一局、终局、倍速、视角、全手牌显示、分析开关、退出回放。

“上一步／下一步”仍按动作帧移动；“上一巡／下一巡”跳到所选视角玩家的相邻出牌回合，略过他人动作。同一巡中的开杠、拔北与补牌不多算一巡，支持跨局和首尾边界。桌沿恢复显示该时刻合法的鸣牌与其他操作及概率，仅供查看，不提交历史动作或改变原牌谱。

## 终盘宝牌显示修复

已用生产中现存的 771 帧牌谱复现：和牌结算时公开的里宝九万，在下一帧 `MatchEnded` 中因结算展示阶段丢失而不再高亮，里指示牌也被隐藏。

新增独立保存的最后结算展示阶段。实战终盘、存档恢复以及已有数据库牌谱的终盘都保留已公开的里宝、赢家揭牌和和牌张排版；新局及重置清除旧结果。真实规则阶段及可操作判断保持终盘状态。

用户已确认麻将普通宝牌和赤五整体不亮由客户端光影导致。ItemDisplay 元数据编码往返验证确认宝牌的 glint override 和模型组件可送达客户端；官方 26.3 客户端也支持该渲染路径。本版保留上述独立且已复现的终盘里宝修复，不增加服务端附魔替代方案或修改材质。当前环境缺少可用 GLX/Vulkan 图形驱动，未完成本版像素级画面验收。

## 验证

本次通过 28 组 Java 回归、17 项 Node 测试及 22 项独立数据库检查。按 `BUILDING.md` 配置依赖后运行 `node build.cjs`、`node test.cjs`。新增回归覆盖策略概率及动作概率总和、真实非最优弃牌、旧缓存失效、四麻与三麻、逐巡跳转、被鸣牌身份、各朝向控件命中、所有座位拔北遮挡、概率字宽、箭头配色、终盘里宝及存档恢复。

此版本构建与代码位于功能分支，正式服仍运行 replay.1；尚未执行本版部署或真实客户端菜单与画面验收。
