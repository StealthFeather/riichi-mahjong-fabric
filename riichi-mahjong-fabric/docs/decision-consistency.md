# 弃牌一致率的比较基准

一致率比较玩家实际打出的牌与该模式的推荐动作。只统计有实质选择的真人弃牌；被迫打出唯一一种牌、自动摸牌和机器人代打不计。相同牌种、相同赤宝状态的不同物理副本视为相同弃牌；普通弃牌与立直弃牌分开比较，赤五与普通五分开比较，日麻独立赖子与普通红中分开比较。

各模式采用其规则可支持的基准：

| 牌局 | 推荐基准 |
| --- | --- |
| 不含娱乐规则的四人日麻，包括雀魂、天凤、WRC、公式战和 M-League | 现有高级电将 AI，使用当前规则配置与合法动作 |
| 三人日麻、川麻，以及开启换三张或血战的牌局（未开赖子） | 本地向听与进张策略：优先减少向听数，再比较公开牌推算的剩余进张，最后保留宝牌、赤宝和役牌 |
| 开启赖子的牌局 | 本地组合牌效策略：保留赖子、对子与顺子连接，合法立直优先；川麻遵守服务端生成的定缺与合法弃牌范围 |

本地三麻策略不会把二至八万计作进张，川麻不会把字牌计作进张。赖子模式采用组合牌效，没有将普通牌向听计算冒充赖子专用向听计算。不同基准的计算强度不同，跨模式的一致率不能直接用作玩家实力的等价排名。

所有推荐在后台计算。输入只含自己的手牌、公开弃牌与副露、已翻宝牌指示牌及当前合法动作；不会读取其他玩家暗手、牌墙顺序、未翻指示牌或里宝牌。弃牌无需等待分析。结果只由服务器线程轮询应用，迟到结果仍归入原来的手与玩家；牌桌重置时取消未完成计算。

标准四麻高级 AI 超时、异常、缺少 Node.js、返回非法动作或任务取消时，该次决策没有一致率样本，不会把降级策略误记为高级 AI 推荐，也不会补成零分。其他模式的本地计算失败或队列已满时同样不产生样本。整场至少有一个有效样本才有该场的一致率分数：成功匹配数 ÷ 有效样本数 × 100，显示为 0–100 分，不带百分号。失败或取消的样本不计入分母。近 10／20／50 局显示最近对应数量完整对局分数的算术平均，窗口内有整场无有效样本时不显示。
