# 0.4.2+fabric.26.3.20

荒牌流局按庄家的实际听牌状态决定是否连庄：庄家听牌连庄，庄家未听换庄。所有流局本场加一；途中流局始终连庄。庄家和牌（含双响中庄家是第二位赢家）连庄并增加本场，闲家和牌本场归零。流局原因随牌桌存档保存，重载后保留；未听罚符、分数及供托正常结转。

吃、碰、杠及立直在服务器接受对应动作时，从麻将桌位置播放原版音效，附近玩家均可听到：

- 吃：`minecraft:entity.player.burp`。
- 碰：`minecraft:block.end_portal_frame.fill`。
- 明杠、暗杠、加杠：`minecraft:block.anvil.place`。
- 立直：四家统一为 `minecraft:item.goat_horn.sound.2`，宣言牌打出时播放一次。仅选中立直按钮、尚未打牌时不播放。

加杠按副露内容变化识别，原有碰升级时也会播放；已有副露不会重复触发。保留弃牌的石头放置音效及其原有参数。

鸣牌响应期间隐藏公共“等待鸣牌响应”提示，个人操作按钮及鸣牌处理照常运行。

验证：完整构建、17 组 Java 回归及 10 项 Node AI 测试。流局回归覆盖三麻和四麻、各庄位及所有听牌组合、庄家和牌、双响、途中流局、存档恢复和下一局本场与分数。服务器部署启动验证另见发布附件；未进行真实客户端试听、画面或完整联机牌局验收。

停服备份后替换旧麻将 JAR 并重启。此次仅使用原版音效和现有显示资产，无需更新资源包。
