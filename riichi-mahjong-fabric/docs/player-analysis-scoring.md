# 玩家分析积分

分析系统的累计积分以整场终局评价点为基础，按规则、三麻/四麻及东风/南风分别保存。正常结束且全程没有机器人操作的雀魂、公式战（JPML A）、M-League 才累计积分；启用换三张、赖子或血战到底的牌局仍记录玩法统计，但不累计积分。无论机器人从开局参与，还是中途临时代打，只要实际执行过操作，该整场对局就不累计积分；仅离座而机器人尚未操作时接回，不影响资格。提前结束或重置牌桌不结算整场积分。

积分与牌局中的点棒独立，内部以 0.1 分保存，避免浮点累计误差。先结算终局剩余立直棒，再计算赛点，每位玩家的累计积分最低为 0。比如原有 10.0 分，本场评价 −25.0，实际减少 10.0，累计变成 0.0；已经为 0 的玩家实际减少 0.0。

| 模式 | 终局评价点 |
| --- | --- |
| 雀魂四麻 | `(终局点棒 − 30,000) / 1,000`，加顺位点 `+15 / +5 / −5 / −15`，头名另加 20 分头名赏 |
| 雀魂三麻 | `(终局点棒 − 40,000) / 1,000`，加顺位点 `+15 / 0 / −15`，头名另加 15 分头名赏 |
| 公式战 JPML A | `(终局点棒 − 30,000) / 1,000`，加浮沉顺位点，见 [竞技规则说明](competitive-rules.md) |
| M-League | `(终局点棒 − 30,000) / 1,000`，加包含头名赏的顺位点 `+50 / +10 / −10 / −30` |

雀魂同分按起家顺序排位；公式战和 M-League 同分平分所占名次的顺位点。算法复用已实现的竞技结算，以终局立直棒分配前的同分关系计算竞技顺位。

这里的雀魂积分为终局评价点。雀魂客户端的段位 pt 还依赖段位、星级和所选房间，本项目没有这些设置，因此不将终局评价点标为雀魂段位 pt。

按本次确认，公式战暂时只累计积分，不设自动升段阈值或段位，也不将累计积分描述为现实连盟的段位认定。
