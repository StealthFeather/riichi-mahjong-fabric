# Timory Mahjong 0.5.0 beta.5

血战到底中，赢家保持站牌且不立即播放胡牌动画。整手结束后，按实际胡牌顺序逐家播放，完成动画的牌面上方显示番数、得点与番种。BossBar 保留战局与各家点数，不再展示胡牌结算详情。

修复已退场赢家承担后续大三元包牌责任时，自摸支付被抵消的问题：责任人已退出时回退到普通自摸分配，仅由仍在场玩家支付；仍在场的包牌责任沿用原规则。增加连续自摸、荣和、抢杠、岭上、包牌、本场、供托及存档重载的点棒回归。

换三张新增抬升与移动动画。四麻每手随机选择顺时针、逆时针或对家互换；三麻随机选择两个有效方向。动画期间暂停出牌，接受换牌后中断或重载直接恢复交换完成的手牌，不重复交换。换出与收到的牌沿用私有手牌可见范围。

此版本无需更换资源包，先部署 Timory_Test 与 Timory_TR_Test 两个测试服。

验证：48 组 Java 回归、10 项 Node 测试通过。Fabric 探针通过川麻四人、日麻三人/四人的延迟展示、5 次中途与 8 次终盘 NBT 恢复、悬浮结果实体生命周期；Timory_Test 服内换牌权限与清理、菜单和观战 HUD 探针通过。尚未进行客户端画面验收。
