# 玩家统计分析

使用 `/mahjong stats` 查看自己的统计，无需靠近牌桌；也可在牌桌设置中点击“我的统计分析”，直接打开该桌当前模式的记录。界面可切换规则、三麻／四麻、东风场／南风场，以及换三张、赖子、血战到底，并分页查看胡牌役种。

每组设置单独保存统计，娱乐玩法的数据不会混入普通对局。统计按玩家 UUID 保存，改名不会丢失记录。

## 胡牌、点炮与役种

每手结算后记录参战真人的已结算手数、胡牌、自摸、荣和与点炮次数，以及胡牌包含的役种次数。一次胡牌可以同时包含多个役种，每个役种在该次胡牌中计一次；役种的番数不会当作重复次数。自摸不计他人点炮；双响等多人荣和分别计每位赢家胡牌，来源玩家在同一手只计一次点炮。流局计已结算手数，不增加胡牌或点炮。

血战到底在本手结束时汇总本手已接受的胡牌，避免结算动画、继续其他玩家的行动或存档重载重复计数。机器人代打仍可继续牌局，但玩家的个人决策分析只采样真人操作。

## 近 10／20／50 局平均一致率

这里的“一局”是一场完整东风场或南风场对局，包含连庄与按规则进行的延长局。本场分数 = 整场已成功分析的真人非强制弃牌中，与参考推荐匹配的次数 ÷ 有效样本数 × 100；窗口分数取最近 N 场完整对局分数的算术平均，每场权重相同。例如 `82.50` 表示平均一致率分数，界面不附百分号。

普通日麻四麻以现有高级 AI 推荐为参考；三麻、川麻和启用了娱乐规则的对局，采用适应该模式合法动作的本地参考策略。因此不同模式的分数采用各自基准，记录分别保存；具体基准见 [弃牌一致率说明](decision-consistency.md)。分析仅使用决策当时该玩家可见的信息；其他玩家暗牌及牌墙未来顺序不提供给分析器。

只有确实有选择的弃牌决策参与比较。相同牌面和赤宝状态的不同实体牌视为同一选择，普通弃牌与宣告立直弃牌分开比较。分析在后台进行，不要求玩家等待推荐。

最近 10、20 或 50 场均有有效分析结果时，才显示该窗口；未满场数或窗口中有整场没有有效分析的记录，则隐藏对应项。失败、超时、不可用或取消的样本排除，不纳入分母；整场没有有效样本时不产生本场分数，包含该场的窗口不展示，不伪造为 0 分。迟到的有效分析会回填原对局，不会新增一次完成对局或再次结算积分。

## 模式积分

普通雀魂四麻、雀魂三麻、公式战（JPML A）与 M-League 在整场正常结束时，按各自规则计算终局评价分并累计到该模式。东风场、南风场及三麻、四麻分别累计。积分规则与计算示例见 [模式积分说明](player-analysis-scoring.md)。

以下条件全部满足才累计积分：未开启换三张、赖子、血战到底；整场没有机器人执行过操作；玩家座位归属未发生替换；对局按规则正常结束。中途结束、重置，以及牌谱回放、预设演示不计积分。某段曾由机器人操作的对局，即使玩家后来接回座位，也不会恢复积分资格。

积分最低为 0。扣分超过当前余额时只扣到 0；余额已为 0 的玩家不再被扣分。终局提示显示实际应用的积分变化。公式战先只累计积分，不设置升段制度。

## 存档

数据位于世界目录 `data/riichi-analysis/<玩家UUID>.json`，包含各模式统计、最近最多 50 场一致率和用于防止重复结算的事件标识。每次更新使用临时文件替换保存；牌桌另外保存当前统计会话及机器人操作标记，以支持重载后继续统计。正常重载、重复显示结算及再次读取同一结算事件不会重复增加计数或积分。

新功能仅记录启用后的真实牌局。原有无分析会话的活动存档、导入牌谱和预设演示不会补算为新的真实成绩；公开牌桌同步数据不包含私人统计存档。
