# 0.4.2+fabric.26.3.13 · 操作交互与弃牌音效

- 主动离座只保留 `/mahjong leave`，取消通过桌子或座位点击离座。
- 相邻操作按钮留出 3 个字符宽的间距，沿用文字背景与点击范围一致的布局。
- 三元牌按钮显示“中”“发”“白”，分别替代原有“3元”“2元”“1元”，对应 rank 3/2/1。
- 跳过可和牌机会前须二次确认：存在荣和（含抢杠）或自摸机会时，点击“跳过”先显示“确认跳过”和“返回”，确认后才放弃。点击荣和或自摸本身仍直接声明；只有吃碰杠机会时，普通跳过仍单击。确认跳过本次自摸后仍可正常打牌。
- 成功弃牌播放 `minecraft:block.stone.place`，类别为 `ambient`，音量 1、音调 2。

保留此前的暗杠显示、普通荒牌流局罚符、弃牌空槽与 10 tick 后合并理牌等行为。

本机验证使用 Minecraft 26.3、Fabric Loader 0.19.5、Fabric API 0.163.0、Java 25 与原版客户端；9 组主回归和 9 项通用服务器集成检查通过。

有原版客户端连接的隔离服务器完成 8 项真实桌实体与私有按钮交互检查，覆盖荣和、抢杠、自摸的跳过确认与返回，伪造及过期确认令牌拒绝，仅命令离座，实际按钮文字与间距，以及已立直玩家确认跳过自摸后恢复自动摸切。

原版客户端对三元牌按钮和密集缩放按钮布局各取得 3 次稳定文本采样，确认中文牌名与字体度量下 27 像素（3 个全角字符宽）的间距；对应截图已复核。另由原版客户端实际执行自摸“跳过→返回→跳过→确认”，并核对服务端状态。荣和及抢杠分支的验收来自服务器侧真实交互检查。

7 个实际客户端声音数据包窗口检查通过：

| 场景窗口 | 石头放置音效包数量 |
| --- | --- |
| 普通弃牌、立直弃牌、BOT 弃牌、重复点击、最后一张弃牌 | 各 1 |
| 非法弃牌、仅处理鸣牌响应 | 各 0 |

收到的音效包均为 `minecraft:block.stone.place`、`AMBIENT` 类别、音量 1、音调 2，发声位置为麻将桌中心。

以上为固定场景测试，未遍历整场多人牌局，也未测量逐帧渲染。本次测试机 OpenAL 音频设备不可用；声音验收只核对客户端收到的数据包，包括 ID、类别、音量、音调、位置和次数，未验收扬声器播放效果。本版实际结果、采样摘要及 JAR SHA-256 见 Release 附件 `verification.json`。

测试探针只用于本机隔离测试，不包含在生产 JAR 中。已有包含当前麻将资产的服务器资源包可继续使用。
