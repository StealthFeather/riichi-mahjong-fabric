# Timory Mahjong 0.5.3-beta.3

右键中心风盘或输入 `/mahjong menu` 打开牌桌菜单。

| 菜单 | 操作 |
| --- | --- |
| 牌桌座次 | 点击桌子四周的风牌入座。入座后显示玩家头像，桌主可点击头像移交桌主。各席位外侧的按钮切换该席 AI 难度。 |
| 玩法设置 | 查看规则、局数、人数及玩法开关。桌主可以修改。 |
| 个人设置 | 选择自己的出牌方式、立直棒外观和胡牌效果。 |
| 历史战绩 | 按日期查阅自己参与的牌谱，查看个人统计和分析，或领取空白牌谱。 |
| 牌桌操作 | 开局、观战、继续下一局及管理牌桌。 |

部署时同步更新服务端 JAR 和 TimoryResource 资源包。
