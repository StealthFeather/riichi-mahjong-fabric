# Timory Mahjong 0.5.0 beta.4

新增独立“血战到底”开关，与换三张、癞子并列，支持全部现有规则及三麻、四麻。所有新牌桌默认关闭，包括川麻。开启显示红石粉，关闭显示火药；仅桌主可在开局前调整，选项随牌桌及对局保存。

关闭时，川麻在首次胡牌响应结束后结束本手，同次多响完整结算；日麻沿用所选预设的正常结算。开启时，赢家退出本手、不再行动或承担后续支付，其余座位继续摸打。三麻累计两名赢家、四麻累计三名赢家，或牌墙耗尽时结束本手。

日麻保留其有役、宝牌、立直、振听、头跳/多响及三家和途中流局规则。供托仅支付一次；赢家、分数、胡牌来源与进行状态随存档恢复。胡牌特效只为本次新增赢家播放。日麻血战使用服务端本地 BOT 策略。

旧版已开始的川麻存档没有独立字段，加载后保留原有血战规则；旧空闲桌与新建川麻默认关闭。此版本使用现有资源包。
