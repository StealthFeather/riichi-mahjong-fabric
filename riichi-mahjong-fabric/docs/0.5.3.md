# Timory Mahjong 0.5.3

本正式版基于 0.5.2，适用于 Minecraft 26.3 Fabric 服务端。

- **荣和动画**。先推倒赢家的手牌，再由微缩末影人搬走点炮牌、唤魔师召唤尖牙吞牌，或由监守者发出尖啸把牌击飞。荣和牌最终停在赢家最右侧摸切位。监守者从点炮牌后一张牌宽处竖直爬出。
- **牌桌菜单**。右键中心风盘或输入 `/mahjong menu`，可入座、移交桌主、调整各席 AI 难度、查看规则和操作牌桌。「个人设置」可以选择自己的立直棒、胡牌效果及出牌方式。「历史战绩」支持按日期查看自己的牌谱、统计和分析。
- **金色宝牌**。宝牌及赤宝牌使用金色模型并保留牌面。暗手的金色模型仅持牌人可见。弃牌、副露及结算摊牌按已公开的指示牌显示，里宝牌在相应结算时公开。
- **血战连庄**。亲家在本手首个和牌事件中获胜（包括一炮多响），或本手无人和牌且流局听牌时连庄。闲家先胡后亲家再胡时轮庄。新存档记录首胡是否为一炮多响。

安装时用 `timory-mahjong-0.5.3.jar` 替换旧版服务端模组，配套完整 TimoryResource 资源包随发布提供。已使用 0.5.3-beta.3 完整资源包的客户端可继续使用该资源包。
