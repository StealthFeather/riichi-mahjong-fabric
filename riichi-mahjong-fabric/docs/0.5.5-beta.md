# Timory Mahjong 0.5.5 Beta

此版基于 0.5.4 正式版。升级时替换服务端模组为 `timory-mahjong-0.5.5-beta.jar`，可继续使用 0.5.4 的 TimoryResource 资源包、Mortal 模型和推理程序。[Mortal 安装说明](0.5.4.md)

## 抽血模式

四位玩家入座后，在牌桌菜单的「玩法设置」中分别点击「抽血模式」。开局前可以撤回。集齐四票后，由桌主在「牌桌操作」中开始对局。投票仅对本场有效。

- 开局时四人的生命值设为 20（10 颗心）。玩家距离桌心不超过 32 格时无法回血。走出范围可以回血，返回后再次禁疗。
- 每实际支付 1,000 点扣 1 生命值，零头按比例计算。支付 1,500 点扣 1.5 生命值。立直时缴纳的 1,000 点供托免扣血。离线期间应扣的血量在重新上线时结算。
- 整场结束时，低于 25,000 点的玩家按与 25,000 点的差额再扣一次。例如以 22,500 点结束时，再扣 2.5 生命值。手动结束、重置和拆桌也会按当时的点数结算。

## 规则修复

- 换三张时，相同的牌可以逐张选取或取消。选中标记、读档后的选择和换牌动画都对应被点击的那一张。
- 三麻中，任一玩家拔北都会打断本手首巡。此后自摸不能获得天和或地和，也不能再宣言双立直。符合条件的玩家仍可宣言普通立直。

## 指定下一局起手向听数

标准日麻四人对局中，管理员可以随时指定同桌一至四名玩家下一局的起手向听数。使用此功能时，换三张、癞子、血战到底和抽血模式须全部关闭。

```text
/mahjong shanten Alice 0 Bob 2
/mahjong shanten Bob 3
/mahjong shanten Bob clear
```

第一条指令让 Alice 下一局起手听牌、Bob 起手 2 向听。第二条只把 Bob 改为 3 向听，第三条撤销 Bob 的设置，让他恢复随机配牌。指令可由 OP 或服务端控制台执行，按玩家名定位牌桌。

数值范围为 0～6。向听数按庄家第一摸前的 13 张牌计算，取普通形、七对子和国士无双的最小值。下一次发牌时，只对当时仍入座的指定玩家生效一次，连庄也算下一局。整场结束后，剩余设置自动清除。
