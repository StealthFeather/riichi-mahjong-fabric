# Timory Mahjong 0.5.0 beta.3

- 日麻换三张允许任意花色的三张普通牌；川麻仍要求三张同花色数牌。癞子不能换出。
- 所有玩家可潜行右键中心风盘或使用 `/mahjong menu` 查看牌桌配置。设置、开局和管理操作仍仅桌主可执行；打开菜单不自动接管现有桌主。
- 配置菜单倒数第二行改为入座操作：点击空位入座，已入座者显示头像，点击自己的头像离座。桌主点击其他玩家头像可在二次确认后移交桌主；旧确认页在换座、换主、换手或重载后失效。
- 该行最右侧为观战按钮，点击进入或退出观战；已入座玩家选择观战会先离座，进行中的座位由 BOT 接替并保留返回资格。
- 第三行第三格控制是否向观战者展示各家手牌：末影之眼为开启，末影珍珠为关闭。默认关闭，桌主可随时调整，选项随牌桌保存。
- 已选择观战的近旁玩家收到与参战玩家相同的战局 BossBar。手牌通过专属显示发送，仅开启展示时可见；普通围观者不获得隐藏牌面。

观战身份不写入存档；离开牌桌范围、断线、入座或牌桌卸载时清除。此版本使用现有资源包。
