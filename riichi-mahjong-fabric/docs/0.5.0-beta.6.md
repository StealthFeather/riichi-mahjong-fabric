# Timory Mahjong 0.5.0 beta.6

新增独立的“公式战”和“M-League”四麻预设。所有玩家可查看设置，桌主在开局前点击第一行相应按钮选择；三麻桌切换后自动恢复四麻。玩法开关（换三张、癞子、血战到底）继续可用，开启时是对应竞技规则的扩展玩法。

公式战按日本职业麻将联盟 A 规则设置，30,000 点持、30,000 点返，无赤宝、一发、里宝及杠宝，顺位点按浮沉人数计算。M-League 25,000 点持、30,000 点返，赤宝三张，有一发、里宝和杠宝，并采用头跳与切上满贯。两套规则的计分与局程细节见 [竞技规则说明](competitive-rules.md)。

规则 Profile 随牌局和牌谱保存，旧存档按原有规则加载；AI 使用实际预设的计分参数。终局显示赛点，点棒仍保留真实结算数值；同分顺位点单独计算。

菜单显示采用服务端中文，不需要更新现有资源包。先更新 Timory_Test、Timory_TR_Test 两个测试服。

立直修正：血战中立直宣言牌被荣和且本手继续时，该立直仍成立并支付供托；本次荣和直接结束本手时才取消未成立宣言。已成立立直的后续放铳、吃碰杠均不解除立直。所有玩家与机器人在立直后只能摸切本次摸到的精确牌张，不能手切旧牌。

为“跳过荣和后再立直”新增实际按钮操作回归，覆盖南场、全部日麻预设、换三张／癞子／血战组合、同次他家胡牌退出、存档重载及立直后永久振听。该流程在规则及按钮测试中可用；保留临时振听、河振听和立直后振听的正常限制。

验证：最终 55 组 Java 回归、11 项 Node 测试通过；Fabric 存档与展示探针通过。Timory_Test 服内六家规则菜单、新规则实际开局与规则重载，以及真实 ServerPlayer 跳过荣和后立直的私有按钮和手牌交互均通过；未做客户端画面验收。
