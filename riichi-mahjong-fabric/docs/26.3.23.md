# 0.4.2+fabric.26.3.23

桌主可在 `/mahjong menu` 中点击离线座位旁的“用 AI 取代”，接替仍占座的离线玩家，或解除离线玩家留下的原座位保留。当前手牌、分数、供托及已经接受的鸣牌决定保留，四麻使用该座位设置的 AI 难度，三麻使用原有机器人。已经由机器人操作的保留座位继续使用当前机器人。替换后原玩家不再有专属原座，回来时可按普通入座规则接管可用座位。

替换只对服务器玩家列表中确实离线的目标生效；在线但在其他维度的玩家不会被替换。点击时重验当前桌主、目标 UUID、座位和对局快照，防止旧菜单误替换刚上线的玩家或后来的占座者。

菜单“结束对局”现在进入二次确认页，与“重置牌桌”共用同一确认布局。结束只清除当前对局并保留入座者；重置还释放所有座位。取消返回设置，点空或关闭不执行。换主、换座、换手、结束、重置或重载后，旧确认页均失效。

原桌主离线时，近旁非旁观玩家可以潜行、主手右键桌面中心取得桌主权限，无需先入座。这一次点击只接管，不会同时开局、推进下一手或结束对局。接管检查实际视线与桌面中心区域，避免整桌虚拟碰撞体把桌沿点击误当中心。桌主在线时不能接管，回归上线也不会自动夺回已转移的权限。

桌主身份独立保存，旧存档兼容原有首位入座者；离座或被 AI 替换不会意外转移桌主。菜单及扳手结束、座位管理、潜行开局／重开和有内容牌谱加载统一检查桌主权限。普通入座、出牌及桌主现有扳手操作保留。

验证：完整构建、23 组 Java 回归及 10 项 Node AI 测试，覆盖离线目标、座位保留撤销、机器人替换保留规则状态、桌主接管及持久化、中心点击几何与过期快照。本版暂未部署；确认页的真实服务器容器点击和客户端交互尚未实测。

保留 26.3.22 的立直横放、结算主动展示及主手镐拆桌要求，以及宝牌私密光效、流局连庄和动作音效。无需更新资源包。
