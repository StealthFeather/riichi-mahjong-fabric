# 0.4.2+fabric.26.3.18

自摸、荣和结算摊牌时，和牌张统一放在本人视角最右侧的摸牌位，与其余手牌相隔三分之一牌宽。自摸从已有手牌中取出实际和牌张，荣和额外显示被荣和的牌；其余暗手牌按原顺序规则整理。保持赤五与普通五的身份区别，支持副露后的短手牌、三麻、四麻、双荣和及抢杠和。

在规则驱动器接受和牌动作时记录当时的活动牌，避免同一 tick 内连续出牌和机器人荣和时记录错牌；这只保留显示信息，不改变手牌、计分或和牌判定。结算显示信息随牌桌存档保存，区块重载或重启后恢复。旧版已经结束且没有保存和牌张的牌局保持原显示；新产生的结算使用新布局。

沿用现有 3×3 桌体、1.5 倍牌尺寸、贴桌高度与材质包。此次修改无需更新材质包。

验证：`node project.cjs build`、`node test.cjs`。新增回归用真实规则动作验证自摸、荣和、双荣和、抢杠和与同帧 BOT 荣和，检查最右和牌张身份、四方向三分之一牌宽间隔、原规则手牌不变，以及 NBT 保存恢复。本版未进行真实客户端画面或完整联机牌局验收。
