# Timory Mahjong 0.5.0 beta.7

新增玩家统计分析：`/mahjong stats` 或牌桌菜单“我的统计分析”进入。按规则、三麻／四麻、东风／南风、换三张／赖子／血战开关分别记录每手的胡牌、自摸、荣和、点炮及胡牌役种次数。

近 10、20、50 局平均一致率按完整对局计算，用 0–100 分显示，不带百分号；局数不足或窗口内有对局没有有效分析时不显示。分析在后台进行，使用本人手牌和公开信息，推荐基准见[一致率说明](decision-consistency.md)。

雀魂四麻／三麻、公式战 JPML A、M-League 的正常终局按各自赛点累计积分，最低为 0。只有未启用三项娱乐规则且整场没有机器人实际操作的对局可计积分；包括摸牌、过牌在内的任意 BOT 动作都会取消整场积分资格，接回座位或重载存档不会恢复资格。公式战只累计积分，暂不设升段规则。

玩家数据按 UUID 保存到当前世界的 `data/riichi-analysis/`，重复结算及重载不会重复计数。导入牌谱与预设练习不写入统计，旧活动牌局从下一场开始启用分析，不追补历史积分。

无需更新资源包。未部署到运行中的服务器，真实客户端交互验证仍需进行。
