# 0.4.2+fabric.26.3.7

## 修复与功能

- 副露展示按出牌者相对方位排列：上家左侧横放、对家中间、下家右侧；保留被鸣牌的赤宝身份，加杠叠放，暗杠两端朝下。
- 立直宣言牌被吃、碰、杠时，使用扣除供托后的最新牌局执行副露，避免覆盖点数和供托。每家立直选择独立；失效的选择不再保留按钮，选中立直后以绿色箭头标记合法弃牌。
- 已作出响应的玩家不再暴露本轮旧操作；不再发送可点击的吃碰杠聊天历史。旧版令牌命令只返回已过期提示。
- 场次、本场、供托、余牌、各家分数和结果使用本人 BossBar；桌上不再有大段悬浮状态文字。
- 轮到玩家出牌，或其可以吃碰杠、立直、胡牌时，用经验条上方的 ActionBar 提示。按钮仅本人可见，始终位于本人一侧，并在操作失效时移除。
- Shift 右键牌桌或本人手牌/操作按钮退出当前牌局，BOT 接管同一手牌、分数和已接受的响应，其他人继续。命令与菜单采用同一退出路径。
- 牌桌显示和虚拟碰撞宽度均缩为 2，中心保持中心方块正中；桌面四侧显示门风，随庄家轮转，当前出牌者高亮。
- 已缴纳的立直棒按家显示；流局结转供托显示在桌心。宣言牌被荣和时不显示未缴供托的棒。

## 实现与验证

`upstream/` 保持原始快照；`rules-patches.cjs` 以匹配校验的方式在构建时修正规则驱动器，生成源码位于 `build/rule-patches/`。构建入口与源码包都包含该补丁。

运行 `node build.cjs`、`node test.cjs`。验证包括三家连续立直、立直宣言牌被碰后的供托和后续立直、已响应候选失效、BOT 接管、三麻/四麻所有相对座位的吃碰杠排列、2×2 中心坐标与四向门风文字朝向，以及各家独立立直按钮。结果写入 `build/verification.json`。

“一家立直后其他家无法立直”在原始纯规则连续立直场景中未复现；本次修复相关供托覆盖和旧操作状态，并补充合法弃牌标记。仍需用原版客户端复核用户原先遇到的交互现象。未启动用户服务器，未执行完整联机牌局、网络协议或客户端视觉验收。

安装须同步更新服务端 JAR 和合并资源包，新版立直棒桌面模型包含在两者中。退出不会删除牌局；旧桌的占位方块布局和存档格式兼容。
