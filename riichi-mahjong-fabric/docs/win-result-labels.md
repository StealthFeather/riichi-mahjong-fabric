# 胡牌结算悬浮文字

每位赢家完成本人的胡牌动画后，在其摊开的手牌上方显示番数、本次实际获得的点数与番种。日麻额外显示符数和宝牌数；番种使用现有中文翻译，川麻使用对应玩法名称。点数取该次已接受结算的赢家增量，不以累计总分代替。

血战在本手结束前保留立牌，结算文字也不提前公开；本手结束后按胡牌顺序播放动画，完成一家后显示该家的结算。多人胡牌的每家保留自己的番种和点数。结算信息随牌桌保存，终盘、重载及重新进入观看范围后可恢复，开始下一手或重置时清除。

BossBar 保留战局信息、各家比分与当前行动提示，不再承担胡牌番数、点数和番种的展示。文字由原版 TextDisplay 显示，无需新材质。
