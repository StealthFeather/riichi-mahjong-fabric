# 0.4.2+fabric.26.3.10 · 手牌闪烁修复

- 修复本人手牌牌面与公共牌背重叠引起的闪烁，包含最右侧普通手牌。公共牌背在注册到虚拟显示前就排除手牌所属玩家，避免首次同步时把牌背同时发送给本人。
- 手牌所属玩家或公开范围变化时，先移除旧显示实体，再按新的可见范围创建；避免旧实体继续留在客户端，影响离座接回及流局公开。
- 保留 `26.3.9` 的桌沿按钮、中央立直棒、右侧摸牌间距、20 tick 后理牌和流局展示听牌手牌等改动。

本机验证使用 Minecraft 26.3、Fabric Loader 0.19.5、Fabric API 0.163.0、Java 25 与原版客户端；6 组回归和 9 项真实服务器集成检查通过。

闪烁问题使用固定北侧手牌区域进行客户端实体采样。旧版 `26.3.9` 在摸牌场景的 30 次采样中，每次都在 14 个牌位发现 28 个显示实体，复现本人牌面与公共牌背重叠。新版验证摸牌、流局公开后返回摸牌状态、旁观者视角、旁观者转为手牌所属玩家四种场景，各采样 30 次，共 120 次；每个牌位均只有一个实体，本人看到牌面、旁观者看到牌背，采样期间实体 ID、模型、位置、缩放与旋转保持稳定。对应截图也已复核。

实体采样验证重叠、可见范围与变换稳定性，不测量逐帧渲染。以上为固定场景测试，未遍历整场多人牌局的所有规则分支。测试探针只用于本机隔离测试，不包含在生产 JAR 中；详细结果及 JAR SHA-256 见 Release 附件 `verification.json`。

本次不修改模型、材质或音效。`26.3.9` 的公开资源包及已有包含当前麻将资产的自定义资源包可继续使用。
