# Timory Mahjong 0.5.1 Beta

本版合入玩家对局分析系统，并保留 0.5.0-beta.6 的公式战、M-League 和立直修复。

输入 `/mahjong stats`，或打开牌桌设置并点击“我的统计分析”，即可查看自己的胡牌、自摸、荣和、点炮及各役种次数。统计按规则、人数、东南场和娱乐玩法开关区分。近 10、20、50 场弃牌一致率按 0–100 分显示，各窗口在场数足够且每场都有有效样本时出现。

无换三张、赖子、血战到底且全程由真人操作的雀魂四麻、雀魂三麻、公式战与 M-League 在正常终局后结算模式积分。积分最低为 0，公式战仅累计积分。[统计与存档说明](player-analysis.md) · [积分规则](player-analysis-scoring.md)

玩家数据随所在服务器的世界保存。统计从升级后新开的真实对局开始，导入牌谱和练习局不计入成绩。沿用现有 TimoryResource 资源包。
