# 资源包发布

测试服使用项目背景中记录的 <https://file.timory.online> 托管。先读取当前完整资源包作为基准，再覆盖本版 `assets/riichi_mahjong/`，逐项确认其余资源保持一致。

新文件使用独立版本名，不能覆盖共用的 `TimoryResource.zip`。通过 API 获取客户端下载地址并回读，核对 SHA-1 后，将对应地址和哈希一起写入测试服配置。带签名的 URL 与 API 令牌只存放在本机受限部署记录中。

`0.5.0-beta.1` 的尖牙是三个可缩放 ItemDisplay：牙床及双颚沿用原版尖牙几何和纹理。原版 EvokerFangs 没有可同步缩放参数，因此新模型定义必须通过资源包送到客户端。

本次尝试同步独立材质仓库时，GitHub 返回 `Repository not found`。新增模型保存在模组源码和资源覆盖目录，测试服发布包以现用完整包为基准，未覆盖共用线上包；独立材质仓库尚未推送。
