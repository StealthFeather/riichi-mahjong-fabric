# 0.4.2+fabric.26.3.22

立直宣言牌被吃、碰或杠拿走后，横放标记转移到其后第一张仍留在牌河中的弃牌。如果后继弃牌也被鸣走，标记继续顺延；原始宣言牌仍在牌河时保持原位。只调整显示，不改立直宣言、供托、弃牌记录或赤牌身份。

每手和牌、流局结算及整场对局结束后，尚未公开手牌的玩家可点击本人桌沿的“展示手牌”按钮，主动向桌旁玩家公开自己的手牌。已经按原规则公开的赢家和听牌手牌照常显示；其他人的手牌及附魔光效继续隐藏。公开选择保存在当前手牌的存档中，重载后恢复；进入下一手或重置牌桌时清除。显示时保留宝牌光效和真实赢家的最右侧和牌张，不给展示手牌的输家补入他人的和牌张。

玩家拆除麻将桌必须主手持 `minecraft:pickaxes` 标签中的任意镐，副手持镐不算，不要求工具等级；创造及生存模式均适用。未持镐时阻止拆除并提示“需要主手持镐才能拆除麻将桌”，提示限频以避免刷屏。检查覆盖桌子全部九个部件、普通挖掘及虚拟碰撞实体的直接破坏入口；单人配对麻将等其他方块保持原行为。

验证：完整构建、21 组 Java 回归及 10 项 Node AI 测试，覆盖被鸣走的立直宣言和连续后继弃牌、主动展示权限及存档生命周期、镐子标签及九个桌体部件。新破坏拦截注入的目标与 Minecraft 26.3 方法签名核对。本版暂不部署服务器，未进行真实客户端画面或完整联机牌局验收。
