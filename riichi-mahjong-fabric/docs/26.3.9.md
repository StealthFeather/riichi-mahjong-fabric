# 0.4.2+fabric.26.3.9

- 吃、碰、杠、立直、荣和、自摸等操作文字平放在所属玩家桌沿上方，使用固定方向和统一字体。显示背景与射线点击矩形共用字体尺寸，检查方块/手牌遮挡；过期按钮不会误触离座。
- 当前声明和跨局供托的立直棒都放在中央风盘上方，显示比例由 0.5 / 0.3 统一缩至 0.22。
- 摸牌保持在右侧，牌边之间空出 1/3 牌宽；公共牌背与本人私有手牌共用坐标。
- 弃牌接受后保留余牌原顺序 20 tick 再理牌，不阻塞规则推进。延迟期间按显示槽位映射实际牌，摸切与新局状态正确清理。
- 流局结算公开全部听牌玩家的手牌，包含未立直和副露听牌；未听牌保持私有。过滤本人已占四枚却被上游判成“等第五张”的无效候选，赤五和普通五合并计数。
- 构建支持本机 Java / Minecraft / Polymer 依赖路径配置，版本号从 fabric.mod.json 读取，测试自动发现所有回归类。

本机验证使用 MC 26.3、Fabric Loader 0.19.5、Fabric API 0.163.0、Java 25 与原版客户端。全部规则、几何、槽位映射及听牌边界回归通过；独立测试 addon 验证真实桌实体、实际服务器 tick、私有显示持有者、流局公开渲染和桌沿操作候选。测试 addon 与客户端探针仅用于隔离测试，不包含在生产 JAR 中。复现说明见 integration/README.md。

本次不修改模型、材质或音效，已有包含麻将资源的 26.3 服务器资源包可继续使用；无需覆盖服务器自定义贴图。完整牌局和所有第三方模组组合不在本次测试范围内。
