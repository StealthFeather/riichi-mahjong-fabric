# 0.4.2+fabric.26.3.25

桌主菜单新增“东风场”和“南风场”两个独立选择按钮，显示当前选择。东风场预定打东场：四麻东一至东四、三麻东一至东三；南风场预定打东、南两场。赛程与雀魂、天凤、WRC 规则预设以及四麻/三麻人数独立，切换规则或人数保留已选赛程。默认南风场，保持旧版对局长度。

模式只可在牌桌空闲时由桌主修改。开局后及整场终盘时均锁定，需要先在菜单确认结束当前对局，再选择下一场模式。修改会使旧菜单与确认页失效，红石自动开局也使用当前模式。连庄、击飞和无人达到返分时的延长沿用所选规则；东风场可能南入，南风场可能西入。

所选模式随牌桌存档及牌谱保存，结束、重置保留该设置。没有新字段的旧空闲牌桌默认南风场；活动对局、终盘或导入的牌谱以其中保存的实际 roundCount 为准，不根据当前场风推断，因此东风场延长到南场后不会变成南风场。练习牌谱保留自身的实际赛程。

本版无需更新资源包。完整构建、26 组 Java 回归及 10 项 Node AI 测试通过，涵盖五种规则预设、三麻/四麻东南终局边界、连庄及延长、牌谱与旧存档兼容；记录见 build/verification.json。仅本地修改，未部署或推送；真实客户端菜单与完整联机牌局尚未实测。
