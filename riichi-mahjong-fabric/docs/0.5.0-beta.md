# Timory Mahjong 0.5.0 beta

本 Beta 汇集当前工作区的麻将功能，面向 Minecraft 26.3 Fabric 服务端，原版客户端可加入。

- 新增四人川麻血战到底，支持定缺、可选换三张与赖子，以及东风场和南风场。
- 空位机器人以原版假人显示，出牌前注视手牌并在出牌时挥手。
- 胡牌特效可选择唤魔尖牙动画或直接摊牌，适用于日麻与川麻。
- 保留日麻规则、牌桌设置、离线座位处理和已有 AI 功能。

需要服务端 Java 25、Fabric Loader、Fabric API 和 Node.js 22 或更高版本（四人日麻 AI 使用）。赖子牌面需要本发布包中的资源包。

本版本为 Beta。自动回归结果见 `verification.json`；真实客户端视觉效果和完整联机牌局仍需验收。
