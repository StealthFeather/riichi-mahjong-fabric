# 公式战与 M-League

菜单第一行追加“公式战”“M-League”，均为四人日麻，默认南风场。原有东风场设置及换三张、癞子、血战开关仍然独立；这些开关启用后属于自定义扩展玩法。

| 项目 | 公式战（JPML A） | M-League |
| --- | --- | --- |
| 起始 / 返分 | 30,000 / 30,000 | 25,000 / 30,000 |
| 赤宝 | 无 | 五万、五筒、五索各一张 |
| 一发、里宝、杠宝 | 无 | 有，含杠里宝 |
| 切上满贯 | 无 | 4 番 30 符 / 3 番 60 符 |
| 连风雀头 | 4 符 | 2 符 |
| 数役满 | 有 | 三倍满封顶 |
| 流局连庄 | 庄家听牌连庄 | 庄家听牌连庄 |
| 不同役满复合 | 允许，单项不加倍 | 允许，单项不加倍 |
| 顺位点 | 按浮沉人数 | +50 / +10 / −10 / −30（含头名赏） |

公式战 30,000 点整计入“浮”。一人浮顺位点为 +12/−1/−3/−8，二人浮为 +8/+4/−4/−8，三人浮为 +8/+3/+1/−12。赛点按相对 30,000 点的素点加顺位点计算，不改变手里的点棒。

M-League 同分者平分所占名次的顺位点，三人同分的小数余数按起家顺序分配。终局流局的剩余立直棒分给第一名；第一名同分时均分，其中三人同分每根按 400/300/300 点分配。供托分配保留终局前的同分关系，避免百点余数打破顺位点的平分。
