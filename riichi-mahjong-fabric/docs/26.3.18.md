# 0.4.2+fabric.26.3.18 · 空点保护与确认重置牌桌

以 GitHub 正式版 `26.3.17`（提交 `a7a073ceb3602df22080c56cd639e7174967ba37`）为基准，保留 3×3 牌桌、新版材质和贴齐桌面的手牌布局。

## 空点保护

未点中吃、碰、明杠、暗杠、加杠、荣和、自摸等按钮时保持等待，不默认跳过，也不默认打出摸到的牌。桌面普通右键不提交玩家动作，不开启、确认或取消跳过和牌提示。操作需明确点击本人当前按钮或手牌；原有明确跳过和牌的二次确认保留。

## 重置牌桌

桌主在 `/mahjong menu` 点击“重置牌桌”，进入独立确认页，再点击“确认重置牌桌”后执行。取消、关闭菜单或点空均不执行。

重置结束当前牌局，关闭 AI，清除比分、供托、手牌、结果动画和返回座位保留，释放所有玩家座位，回到可重新入座开局的状态。桌子、库存、规则、AI 难度、供牌设置及座位启用配置保留。

确认时重新检查桌主、距离、世界、当前菜单和牌桌身份。已取消、已关闭、旧牌局、牌桌卸载后及重复点击的确认不能影响后来新开的牌局。

## 安装与验证

替换旧麻将 JAR 并重启服务端。由 `26.3.15` 或更早版本升级时，应同时使用新版完整资源包，以匹配 3×3 牌桌与材质。随附资源包以正式服完整包为基准，仅更新麻将命名空间，保留其他模组资源。

验证记录见随附 `verification.json`：构建、Java / Node 回归检查，以及隔离 Minecraft 服务端的真实菜单、确认与重置状态检查。本次不宣称已完成可见客户端视觉验收或完整多人实战。
