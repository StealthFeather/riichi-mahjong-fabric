# Timory Mahjong 0.5.0 beta.1

- 开局前隐藏所有机器人假人，入座按钮位于各桌沿的正中；对局中仍可直接点击假人接替对应座位。
- 胡牌尖牙沿用原版纹理与双颚咬合表现，最大高度缩为竖放麻将牌的 4/3。通过可缩放显示模型实现，需要本版资源包。
- 换三张、癞子可在雀魂、天凤、WRC、川麻全部规则预设中使用，支持现有的三麻、四麻和东风场、南风场。开局后选项锁定，默认关闭。

换三张在配牌结束后、庄家首次摸牌前进行。所有玩家确认后同时交换，不提前公开换入的牌。三麻在两个方向中随机选择，四麻使用三个方向；川麻换牌后继续定缺。日麻可换同一数牌花色、风牌或三元牌中的三张普通牌，癞子不能换出。机器人自动选择，玩家可在确认前重新选择。选择、确认及完成状态随存档保留，下一手重新换牌。

开启癞子时每人起手获得一张癞子和十二张普通牌，癞子不进入可摸牌墙。日麻保留普通红中，使用独立身份的癞子；癞子参与胡型、听牌、振听、役种及符数判断，不当作赤宝牌，不可被荣和或吃碰杠。日麻仍须满足原规则的有役条件，宝牌、供托、死墙及三麻拔北规则保留。癞子模式使用服务端本地合法动作策略；原有四麻三级外部 AI 在关闭癞子时照常使用。

自动验证结果见 `verification.json`。客户端真实画面、咬合观感和完整联机牌局仍需进服验收。
