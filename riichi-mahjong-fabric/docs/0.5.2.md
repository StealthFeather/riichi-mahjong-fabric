# Timory Mahjong 0.5.2

本次更新基于 0.5.1 正式版，适用于 Minecraft 26.3 Fabric 服务端。

## 出牌方式

默认右键自己的手牌即可出牌。按住 Shift 右键中心风盘，点击 **我的出牌方式** 可启用 **二次确认**。首次右键选中一张可打的手牌，该牌显示仅本人可见的金色轮廓。再次右键该牌即可打出，右键另一张可打的牌即可改选。两张牌的牌面相同时，也可以分别选中。每位玩家都能在对局中切换出牌方式，重新登录后仍沿用个人选择。

## 吃碰后的杠牌限制

日麻吃、碰后以及川麻碰后，在这次出牌前不能立即暗杠或加杠。等自己下次摸牌后，合法的暗杠和加杠会再次出现在牌桌按钮中。直接杠他家的弃牌，以及杠后补牌再开杠，仍按各玩法的规则处理。

## 安装

停服后，用 `timory-mahjong-0.5.2.jar` 替换服务端 `mods/` 中的旧版麻将 JAR，再启动服务器。玩家使用原版客户端和 0.5.1 的 TimoryResource 资源包即可。
