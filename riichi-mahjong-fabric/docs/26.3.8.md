# 0.4.2+fabric.26.3.8

- Shift 右键只有命中桌子才退出。命中自己的手牌或本人按钮时仍执行正常牌局操作；命中其他公开牌时不离座。
- 桌子点击入口先用玩家视线与牌模型的真实旋转边界求交，优先处理挡在桌面前的牌；同一玩家的私有交互还会抑制紧邻的桌面回调，防止一次点击重复触发离座。
- 中途离开后，BOT 暂代原座位；普通右键桌子或 `/mahjong join` 优先接回原座位。接回保留 BOT 当前手牌、分数、轮次与已经接受的鸣牌响应，不重新发牌。
- 原座位为离开的玩家保留，玩家不能借重返切换到其他家手牌。尚未分配给真人的 BOT 空位可在中途加入。座位保留信息随当前牌局存档保存，开新场比赛或结束比赛时清理。

执行 `node build.cjs`、`node test.cjs`。本版新增四向立放/平放牌的射线命中、空白桌面与遮挡检查，以及原座位保留、保留信息恢复和 BOT 转回真人后继续出牌的回归。已有立直、供托、副露方向与布局检查保留。客户端实际鼠标点击和完整联机牌局仍需复核。
