# 0.4.2+fabric.26.3.16

基于 GitHub `StealthFeather/riichi-mahjong-fabric` 的 main 提交 `decaf7b762d68dfad8ef52bfc47c982c0c3b94e0`（26.3.15）同步，保留四麻三级 AI、TP 返回显示恢复、跳过和牌确认、手牌空槽延迟整理等最新功能。固定原始 `upstream/` 的游戏逻辑与资源不改写。

牌桌水平尺寸由 2×2 格扩大为以中心方块正中为中心的 3×3 格，桌体高度不变。所有麻将牌的长、宽、高、牌间距及相对桌面的高度统一放大 1.5 倍；包含手牌、摸牌、牌山、王牌、弃牌、副露及拔北牌。摸牌与上一张牌仍保留 1/3 牌宽的间隔，避免对已缩放牌宽再次放大。

单张手牌和空槽的交互范围、桌沿按钮的文字与命中平面、座位文字、门风及立直棒同步调整。客户端虚拟潜影贝与服务端移动碰撞均为 3×3；方块选择轮廓和点击遮挡也使用对应范围。单人配对麻将维持原尺寸。

版本元数据、构建 JAR、打包及本地安装入口统一使用 26.3.16。构建默认路径兼容 Timory 工作区及独立源码归档。

验证：`node project.cjs build`、`node test.cjs`；涵盖 3×3 居中、桌边遮挡、1.5 倍牌尺寸、四个方向的摸牌间隔和按钮文字/命中对齐，以及同步版本的全部规则、交互和 AI 回归。验证结果及当前 JAR 哈希见 `build/verification.json`。本版未进行真实客户端视觉或完整联机牌局验收。
