# 换三张

开启换三张后，配牌结束且庄家首次摸牌前，每位玩家选择三张普通牌并确认，全部确认后同时交换。癞子不可换出。

雀魂、天凤、WRC 的三麻和四麻可任选三张普通牌，允许混合万、筒、索、风牌和三元牌。确认前，再点一次已选的那张牌即可取消。手里有多张相同的牌时，每张都可以单独选取或取消，也可以一次清空重选。异花色选择及确认状态会保存在牌桌存档中，重载后继续。

川麻仍要求选择三张同花色的数牌，换牌后继续定缺。

三麻从两个交换方向中随机选择，四麻从三个方向中随机选择。机器人自动选牌，玩家确认前不会收到其他座位的牌。交换仅改变暗手牌，不改变牌墙、宝牌、死墙、积分和供托；进入下一手时重新进行换三张。
