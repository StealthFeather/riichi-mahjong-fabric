# AI 座位假人和出牌动画

对局开始前不显示假人，启用的空座位在对应桌沿正中显示朝上的入座按钮，右键按钮入座。开局后由 BOT 控制的座位显示 Minecraft 26.3 原版 mannequin，使用原版默认玩家皮肤。假人面向牌桌，通过不可见、不可选中的 marker 座椅保持坐姿。真人入座时隐藏假人，由 BOT 接管时恢复；关闭的座位不显示。对局中可直接右键假人接替 BOT，沿用原有的座位保留及距离校验；结束并清空当前对局后假人消失，恢复桌沿入座按钮。

日麻四麻各难度 AI、三麻及川麻 BOT 选定弃牌后先锁定该动作，看向对应的实际手牌位置至少 0.25 秒，再提交出牌。看牌时间与原有随机思考同时进行。普通弃牌和立直宣言牌均使用此流程，实际弃牌被规则引擎接受后播放一次原版主手攻击挥动，并短暂保持注视。

假人仅通过 Polymer 虚拟实体发送给牌桌的观众，不占在线玩家名额，不写入世界存档。传给客户端的是看牌方向，不包含暗牌的物品或牌面。看牌位置沿用手牌显示槽位及摸牌间隔，重复牌选择与实际移除策略一致。

牌桌卸载、旋转、拆除及服务器停止时，假人与座椅随显示 holder 清理。新观众会收到载具、假人和乘坐关系；重新进入可见范围、换局或重载不会补播历史弃牌动作。

构建和回归使用现有入口：

```sh
node build.cjs
node test.cjs
```

新增 `BotDiscardAnimationRegression` 验证看牌先于出牌、候选锁定、立直、随机思考兼容、失效请求取消及关闭清理。隔离的 `BotAvatarIntegrationTest` 用于 Fabric 初始化中的原版注册及协议验证，不属于正式模组入口。构建和协议检查不代表已完成真实客户端坐姿、注视和挥手的视觉验收；具体运行结果保存在 `build/verification.json` 及本次假人验证记录中。
