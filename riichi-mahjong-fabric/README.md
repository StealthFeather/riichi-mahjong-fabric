# Riichi Mahjong

日本立直麻将、3D 牌桌、私有手牌与原版客户端适配。当前本地构建：**0.4.2+fabric.26.3.23**（暂未部署或上传 GitHub），仅安装到 Fabric 服务端。

本版新增离线座位 AI 接替、菜单结束对局二次确认和离线桌主接管。保留 26.3.22 的立直横放标记继承、终盘主动展示及主手持镐拆桌要求（创造模式同样适用）。保留 26.3.21 的实际宝牌和赤宝牌原版附魔光效，未公开暗手的牌面及光效仅本人可见。保留 26.3.20 的流局连庄与本场修复、吃碰杠立直音效和隐藏鸣牌等待提示，以及四麻三级 AI、TP 返回显示恢复、跳过和牌确认、手牌空槽延迟整理及交互布局。变更见 [26.3.23 说明](docs/26.3.23.md)。

## 3×3 牌桌

牌桌显示、方块选择轮廓及客户端/服务端玩家碰撞均为以中心方块正中为中心的 **3×3 格**。桌体高度保持不变。所有麻将牌的长宽高、排列间距及相对桌面高度同步放大 **1.5 倍**；手牌、牌山、弃牌、副露、拔北牌与王牌使用相同比例。

手牌及空槽的点击范围、桌沿操作按钮的文字和命中区域、座位与门风文字、立直棒同步调整。摸牌仍与上一张牌留出 1/3 牌宽的间隔；自摸、荣和的和牌张在结算摊牌时也放在最右摸牌位，并保留相同间隔。竖立手牌与摊开手牌按模型底面贴齐桌面，本人手牌、公共牌背和点击区域共用对应位置。单人配对麻将保持原尺寸。

## 安装与操作

需要 Minecraft 26.3、Fabric Loader 0.19.5、Fabric API 0.163.0+26.3、Java 25；四麻 AI 需要服务端可执行 Node.js 22+。Polymer 和固定版本 AI 源码已内嵌。玩家使用原版客户端并接受包含麻将资产的 TimoryResource。宝牌光效使用原版组件，沿用 26.3.20 的原版音效，无需更新资源包。

本地构建产物为 `riichi-mahjong-0.4.2+fabric.26.3.23.jar`，当前暂未部署或上传；已发布版本见 [GitHub Releases](https://github.com/StealthFeather/riichi-mahjong-fabric/releases)。需要安装时，停服备份后替换服务端旧版麻将 JAR，再正常开服，保留当前 TimoryResource 资源包。

`/mahjong` 查看操作，管理员 `/mahjong give` 领物品。右键桌边入座，桌主潜行右键中央开局，右键自己的牌出牌；吃碰杠、立直与胡牌使用本人桌沿按钮。跳过可和牌机会需要确认。主动离座使用 `/mahjong leave`；离座后 BOT 暂代，右键桌子或 `/mahjong join` 可接回原座位。

扳手右键中央或 `/mahjong menu` 打开设置，支持四麻/三麻规则预设；四麻可选择初级、中级或高级 AI。完整暗牌仅保存在服务端，牌面只发送给所属玩家。

实际宝牌及赤宝牌的附魔光效覆盖本人暗手、公开弃牌、副露及结果摊牌，开杠新翻宝牌后自动刷新。里宝牌仅在立直赢家结算公开里指示牌后参与高亮。本人暗手牌的牌面和光效只发送给本人；他人与旁观者看到的暗手、牌墙和暗杠外侧保持无光效牌背。

牌的交互体积按模型实际显示边界生成，手牌及单人配对麻将的宽、高、厚度均与显示对齐。四麻全部 AI 难度与三麻机器人每次决策随机等待 0.5–1.5 秒。

点空不会默认弃牌或跳过。菜单“结束对局”与“重置牌桌”共用二次确认页：结束清除当前对局并保留入座者，重置还释放全部座位；取消返回设置，点空或关闭不执行，旧对局或换主后的菜单不能继续确认。

桌主可在设置中选择“用 AI 取代”接替离线占座者或解除离线原座保留，保持当前手牌、分数、供托及已接受的鸣牌决定。已有机器人继续使用当前控制器，四麻按座位 AI 难度操作，三麻使用原有机器人。目标须在整个服务器中离线，其他维度的在线玩家不会被替换；原玩家回来后按普通规则选择可用座位。

桌主离线时，近旁非旁观玩家可潜行、主手右键桌面真实中心接管权限，无需先入座。此次点击只接管，不同时开局、推进下一手或结束对局。桌主在线时不能接管，原桌主上线不会自动夺回权限。桌主身份独立保存，离座或被 AI 替换不会意外转移。

立直宣言牌被吃、碰或杠拿走后，横放标记继承到其后第一张仍留在牌河中的弃牌；后继牌再次被鸣走时继续顺延，原始弃牌记录及赤牌身份保持不变。

和牌、流局结算及整场对局结束后，尚未公开手牌的玩家可点击本人桌沿的“展示手牌”，主动公开自己的手牌与宝牌光效；其他人的未公开手牌保持隐藏。公开选择随当前手牌存档保存，进入下一手或重置时清除，展示输家手牌不会补入他人的和牌张。

拆除麻将桌的全部九个部件均要求主手持 `minecraft:pickaxes` 标签中的任意镐，副手镐不算，不要求工具等级；创造和生存模式同样适用。未持镐时阻止破坏并显示限频提示“需要主手持镐才能拆除麻将桌”，覆盖普通挖掘及攻击虚拟碰撞实体的直接破坏入口。单人配对麻将等其他方块保持原行为。

荒牌流局时庄家听牌连庄、未听换庄，所有流局本场加一；途中流局始终连庄，庄家和牌连庄且本场加一，闲家和牌本场归零。流局原因随存档保存。

吃播放 `minecraft:entity.player.burp`，碰播放 `minecraft:block.end_portal_frame.fill`，明杠、暗杠和加杠播放 `minecraft:block.anvil.place`。四家立直统一播放 `minecraft:item.goat_horn.sound.2`，宣言牌打出时播放一次。鸣牌响应期间隐藏公共等待提示，个人操作按钮及响应处理正常运行。

## 构建与验证

在本项目目录执行：

```powershell
node build.cjs
node test.cjs
```

构建器兼容 Timory 工作区与独立源码归档，需配置 JDK、Minecraft 和 Polymer 依赖。配置方式见 [BUILDING.md](BUILDING.md)。**不要重新运行 `prepare.cjs`、`adapt.cjs` 或 `resources.cjs`**，以免覆盖已移植内容及版本元数据。

JAR 位于 `build/libs/`，回归结果和 JAR SHA-256 位于 `build/verification.json`。本版验证包含 23 组 Java 回归及 10 项 Node AI 测试，保留指示牌循环、赤宝牌、开杠翻牌、里宝牌公开条件及原版光效组件检查，保留立直牌河横放继承、终盘主动公开及存档生命周期、动态镐子标签和九个桌体部件检查，新增离线目标、座位保留撤销、机器人替换保留规则状态、桌主接管及持久化、中心点击几何和过期快照回归；本版尚未部署服务器，确认页的真实服务器容器点击及客户端交互尚未实测，也未进行真实客户端可见性、试听、视觉或完整联机验收。

可选打包入口为 `node package.cjs`，默认输出至工作区 `deploy/`；用 `RIICHI_RELEASE_DIR` 可指定其他目录。`install-local.cjs` 仅供正常停服后的主测试服安装，构建与打包不会自动部署。
