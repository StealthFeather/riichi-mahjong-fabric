# Riichi Mahjong

日本立直麻将、3D 牌桌、私有手牌与原版客户端适配。当前正式版：**0.4.2+fabric.26.3.29**，仅安装到 Fabric 服务端。

保留 26.3.24 的中心风盘桌主菜单入口与菜单内开局，鸣牌风牌名称显示为“东、南、西、北”。保留 26.3.23 的离线座位 AI 接替、菜单结束对局二次确认和离线桌主接管。保留 26.3.22 的立直横放标记继承、终盘主动展示及主手持镐拆桌要求（创造模式同样适用）。保留 26.3.21 的实际宝牌和赤宝牌原版附魔光效，未公开暗手默认仅本人可见，开启观战后允许符合条件的观众查看。保留 26.3.20 的流局连庄与本场修复、吃碰杠立直音效和隐藏鸣牌等待提示，以及四麻三级 AI、TP 返回显示恢复、跳过和牌确认、手牌空槽延迟整理及交互布局。变更见 [26.3.24 说明](docs/26.3.24.md)。

## 东风场与南风场

桌主菜单提供“东风场”和“南风场”两个独立赛程按钮，默认南风场，四麻与三麻都可选择。东风场预定打东场（四麻东一至东四、三麻东一至东三），南风场预定打东、南两场。规则预设和人数切换不重置赛程，连庄、击飞及未达返分时的延长仍按原规则执行；东风场可能南入，南风场可能西入。

仅桌主可在牌桌空闲时修改，活动和终盘期间锁定，需先确认结束当前对局再选择下一场。设置随牌桌保存，结束或重置后保留。旧空闲桌缺省南风场；活动对局、练习牌谱和数据库回放以保存的实际 roundCount 为准，延长到其他场风时不会误改模式。详见 [26.3.29 说明](docs/26.3.29.md)。

## 观战

桌主可在牌桌菜单中开启或关闭“观战显示手牌”，设置默认关闭并随牌桌保存，可在实战中切换。开启后，附近非参赛者（包括 Minecraft 旁观模式玩家）可看到各家暗手及宝牌光效；当前座位、离座保留者及本场曾参赛者不视作观众。观众入座或开关关闭后收回观战视图，正常中途入座与重连规则不变。旧对局从座位、保留座位和可用牌谱记录恢复已知参与者；公开结算及牌谱回放规则不变。详情见 [26.3.28 说明](docs/26.3.28.md)。

## 牌谱回放与分析

完整对局自然结束后自动存入现有 Quest 数据库；手动结束或重置的未完成对局不作为完整牌谱保存。主手右键“牌谱” → 玩家概况 → 我的牌谱 → 红中日期 → 当天记录。日历中其他日期显示白板，日期作为物品名称；当天记录按结束时间从新到旧排列，东南西北四项显示各座分数，发财切换分析开关。点击每行首项，将记录载入 8 格内自己拥有、无进行中对局且无其他真人在座的牌桌。牌谱物品不再保存桌面设置，预设练习牌谱仍可使用。

控件跟随所选视角：牌河右侧两行依次是“上一巡、上一步、播放／暂停”和“下一巡、下一步、倍速”；左侧为开局、上一局、下一局、终局、视角、显示／隐藏他家手牌、分析开关和退出。“上一巡／下一巡”跳到所选玩家的相邻出牌回合，同一巡中的开杠、拔北、补牌不重复计巡。桌沿复用实战按钮显示当时合法操作及其概率，仅供查看，不提交历史动作。

分析从现有麻将 AI 评估建立明确的 softmax 策略概率，**不是 AI 原生概率或胜率**。全部弃牌牌种与全部合法操作分别独立归一，完整分布的整数分数各自合计 100，单一选择的内部数值可为 100。候选按34种牌归并，赤五与普通五共用分数；手牌只显示概率前三且整数分数至少1的牌种，每种只显示一个两位数字分数（不足两位前补0，显示上限99）；桌沿操作分数使用相同格式，一致性评分的满分仍为100；历史实际出牌只标一个箭头，最大概率为绿、第二／第三为黄、其他为红，并跟随到准确的牌河或副露。本局一致性评分按各次出牌相对最优概率的比值评分后取平均，最优为100；整场评分按整场所有出牌取平均，只显示在牌谱列表玩家物品说明中。

读取并复用 `config/timory_quest_server.json` 的 MySQL 连接设置及时区，使用三张麻将专用表，不修改 Quest 配置及业务表。旧牌谱继续可读，旧分析缓存会按版本3重算；写库暂时失败时记录保留在世界目录的 `data/riichi-replay-outbox/` 后补传。终盘保留最后结算已公开的里宝牌、赢家手牌及和牌张展示；普通宝牌和赤五光效仍可能受客户端光影影响。

控件变更及本版验证范围见 [26.3.27 说明](docs/26.3.27.md)；数据库结构、概率公式及恢复见 [26.3.26 说明](docs/26.3.26.md) 和 [AI 策略模型](ai/README.md#replay-policy-probabilities-cache-version-3)。

## 3×3 牌桌

牌桌显示、方块选择轮廓及客户端/服务端玩家碰撞均为以中心方块正中为中心的 **3×3 格**。桌体高度保持不变。所有麻将牌的长宽高、排列间距及相对桌面高度同步放大 **1.5 倍**；手牌、牌山、弃牌、副露、拔北牌与王牌使用相同比例。

手牌及空槽的点击范围、桌沿操作按钮的文字和命中区域、座位与门风文字、立直棒同步调整。摸牌仍与上一张牌留出 1/3 牌宽的间隔；自摸、荣和的和牌张在结算摊牌时也放在最右摸牌位，并保留相同间隔。竖立手牌与摊开手牌按模型底面贴齐桌面，本人手牌、公共牌背和点击区域共用对应位置。单人配对麻将保持原尺寸。

## 安装与操作

需要 Minecraft 26.3、Fabric Loader 0.19.5、Fabric API 0.163.0+26.3、Java 25；四麻 AI 需要服务端可执行 Node.js 22+。Polymer 和固定版本 AI 源码已内嵌。玩家使用原版客户端并接受包含麻将资产的 TimoryResource。宝牌光效使用原版组件，沿用 26.3.20 的原版音效，无需更新资源包。资源包附件沿用 26.3.19 的完整发布包，保留包内高清物品图标；本次更新无需更换既有资源包，首次安装可使用此附件。

从 [26.3.29 Release](https://github.com/StealthFeather/riichi-mahjong-fabric/releases/tag/v0.4.2%2Bfabric.26.3.29) 的固定提交文件链接下载 `riichi-mahjong-0.4.2+fabric.26.3.29.jar`。停服备份后替换服务端旧版麻将 JAR，再正常开服，保留当前 TimoryResource 资源包。

`/mahjong` 查看操作，管理员 `/mahjong give` 领物品。右键桌边入座，桌主潜行右键中心风盘打开菜单，再点击“开始对局”；已入座玩家在结算动画完成后普通右键中心风盘进入下一把。右键自己的牌出牌；吃碰杠、立直与胡牌使用本人桌沿按钮。跳过可和牌机会需要确认。主动离座使用 `/mahjong leave`；离座后 BOT 暂代，右键桌子或 `/mahjong join` 可接回原座位。

仅桌主可潜行右键中心风盘或使用 `/mahjong menu` 打开设置（`/mahjong start` 同样进入菜单）。首次打开无主牌桌菜单时认领桌主，已有桌主不会被命令替换。菜单支持四麻/三麻规则预设；四麻可选择初级、中级或高级 AI。整场终盘后先在菜单确认结束，再点击开始新对局。完整牌局保存在服务端，暗手默认只发送给所属玩家；桌主开启观战后，符合条件的观众也可查看。

实际宝牌及赤宝牌的附魔光效覆盖本人暗手、公开弃牌、副露及结果摊牌，开杠新翻宝牌后自动刷新。里宝牌仅在立直赢家结算公开里指示牌后参与高亮，并保留到整场终盘。客户端光影或渲染设置可能影响附魔光效显示。暗手牌面及光效默认只发送给本人；开启观战后符合条件的观众也可查看，其他对局玩家仍看不到暗手。牌墙和暗杠外侧保持无光效牌背。

牌的交互体积按模型实际显示边界生成，手牌及单人配对麻将的宽、高、厚度均与显示对齐。四麻全部 AI 难度与三麻机器人每次决策随机等待 0.5–1.5 秒。

点空不会默认弃牌或跳过。菜单“结束对局”与“重置牌桌”共用二次确认页：结束清除当前对局并保留入座者，重置还释放全部座位；取消返回设置，点空或关闭不执行，旧对局或换主后的菜单不能继续确认。

桌主可在设置中选择“用 AI 取代”接替离线占座者或解除离线原座保留，保持当前手牌、分数、供托及已接受的鸣牌决定。已有机器人继续使用当前控制器，四麻按座位 AI 难度操作，三麻使用原有机器人。目标须在整个服务器中离线，其他维度的在线玩家不会被替换；原玩家回来后按普通规则选择可用座位。

桌主离线时，近旁非旁观玩家可潜行、主手右键真实中心风盘接管权限，并在同一次点击打开菜单，无需先入座；不会同时开局、推进下一手或结束对局。桌主在线时不能接管，原桌主上线不会自动夺回权限。桌主身份独立保存，离座或被 AI 替换不会意外转移。

立直宣言牌被吃、碰或杠拿走后，横放标记继承到其后第一张仍留在牌河中的弃牌；后继牌再次被鸣走时继续顺延，原始弃牌记录及赤牌身份保持不变。

和牌、流局结算及整场对局结束后，尚未公开手牌的玩家可点击本人桌沿的“展示手牌”，主动公开自己的手牌与宝牌光效；其他人的未公开手牌默认保持隐藏；桌主开启观战时符合条件的观众可查看。公开选择随当前手牌存档保存，进入下一手或重置时清除，展示输家手牌不会补入他人的和牌张。

拆除麻将桌的全部九个部件均要求主手持 `minecraft:pickaxes` 标签中的任意镐，副手镐不算，不要求工具等级；创造和生存模式同样适用。未持镐时阻止破坏并显示限频提示“需要主手持镐才能拆除麻将桌”，覆盖普通挖掘及攻击虚拟碰撞实体的直接破坏入口。单人配对麻将等其他方块保持原行为。

荒牌流局时庄家听牌连庄、未听换庄，所有流局本场加一；途中流局始终连庄，庄家和牌连庄且本场加一，闲家和牌本场归零。流局原因随存档保存。

风牌按钮显示“东、南、西、北”，不再使用“1风、2风、3风、4风”；白、发、中及数字牌名称保留。吃播放 `minecraft:entity.player.burp`，碰播放 `minecraft:block.end_portal_frame.fill`，明杠、暗杠和加杠播放 `minecraft:block.anvil.place`。四家立直统一播放 `minecraft:item.goat_horn.sound.2`，宣言牌打出时播放一次。鸣牌响应期间隐藏公共等待提示，个人操作按钮及响应处理正常运行。

## 构建与验证

在本项目目录执行：

```powershell
node build.cjs
node test.cjs
```

构建器兼容 Timory 工作区与独立源码归档，需配置 JDK、Minecraft 和 Polymer 依赖。配置方式见 [BUILDING.md](BUILDING.md)。**不要重新运行 `prepare.cjs`、`adapt.cjs` 或 `resources.cjs`**，以免覆盖已移植内容及版本元数据。

JAR 位于 `build/libs/`，回归结果和 JAR SHA-256 位于 `build/verification.json`。另运行 `node test-replay-database.cjs /path/to/h2-2.3.232.jar` 验证独立测试数据库；结果位于 `build/replay-database-verification.json`。本版完整构建、31 组 Java 回归及 19 项 Node 测试通过，SC 与 TR 均确认加载 26.3.29 并通过状态连接和控制台命令响应检查，其他模组与配置保持。按用户要求未创建新世界快照，仅备份旧 JAR 和配置；具体启动日志范围见发布清单 `release.json`。本版构建结果以对应发布附件为准；26.3.25 的历史数据库检查见 [26.3.25 说明](docs/26.3.25.md)。本版尚未进行真实客户端视觉、菜单交互或完整联机牌局验收。

可选打包入口为 `node package.cjs`，默认输出至工作区 `deploy/`；用 `RIICHI_RELEASE_DIR` 可指定其他目录。`install-local.cjs` 仅供正常停服后的主测试服安装，构建与打包不会自动部署。
