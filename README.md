# Riichi Mahjong — Fabric 26.3 服务端移植

基于 [caxapexac/MinecraftRiichiMahjong](https://github.com/caxapexac/MinecraftRiichiMahjong) 的独立 Fabric 服务端移植，保留原项目麻将规则、3D 模型、材质和音效。仅服务端安装 Mod，玩家使用原版客户端并接受资源包。

当前正式版：`0.4.2+fabric.26.3.26`。完整完成的对局自动存入现有 Quest 数据库，通过牌谱物品打开个人牌谱日历，在自己的空闲牌桌上回放并查看 AI 策略概率。支持逐步、上下巡和上下局回放，控件位于选中视角牌河的左右两侧；实际出牌按完整候选排名显示一个彩色箭头。终盘继续保留已公开的里宝牌、赢家手牌及和牌张展示。用法与验证范围见 [26.3.26 说明](riichi-mahjong-fabric/docs/26.3.26.md)。

保留 26.3.24 的中心风盘桌主菜单与菜单内开局、风牌名称“东、南、西、北”；保留 26.3.23 的离线座位 AI 接替、结束对局二次确认和离线桌主接管。保留 26.3.22 的立直横放标记继承、终盘主动展示及主手持镐拆桌要求（创造模式同样适用），以及 26.3.21 的实际宝牌和赤宝牌原版附魔光效，未公开暗手的牌面及光效仅本人可见。保留 26.3.20 的流局连庄与本场修复、吃碰杠立直音效和隐藏鸣牌等待提示，以及模型边界交互、0.5–1.5 秒随机 BOT 思考、最右和牌张、空点保护和确认重置。适用于 Minecraft **26.3**、Fabric Loader **0.19.5**、Fabric API **0.163.0+26.3**、Java **25**。

保留四麻初级／中级／高级电将 AI、默认及各座位难度设置、存档恢复与离座接管。服务端需 Node.js 22+；固定版本 AI 源码与 MIT 许可已内嵌，无需 npm 安装或远程 AI 服务。三麻仍使用原 BOT。难度尚未通过大规模同牌山对战标定，详见 [四麻 AI 说明](riichi-mahjong-fabric/docs/26.3.15.md)。

`26.3.14` 修复玩家 TP 离开后返回看不见麻将桌的问题：同步玩家显示观察关系，区块卸载时清理旧显示，返回后恢复桌体、桌上公共牌及本人手牌；同时处理显示附件失效和异步区块加载的恢复。此次修复无需更新资源包。构建、9 组主回归、9 项通用服务器集成及 5 次实际 TP 往返检查通过；针对性验证详见 [26.3.14 变更与验证](riichi-mahjong-fabric/docs/26.3.14.md)。

本版牌桌为居中的 3×3 格，麻将牌与排列间距按 1.5 倍放大。竖立和摊开的手牌按模型底面贴齐桌面，本人手牌、公共牌背与点击区域同步对齐。材质重复铺设不做平滑插值，保持像素一致性。详见 [26.3.17 说明](riichi-mahjong-fabric/docs/26.3.17.md) 和 [材质说明](riichi-mahjong-fabric/docs/materials-lime-quartz.md)。

牌谱功能实现已通过 28 组 Java 回归、17 项 Node 测试及 22 项独立数据库检查；正式版附件的构建哈希与验证结果以 `verification.json` 和 `replay-database-verification.json` 为准。尚未完成本版真实客户端像素级画面、菜单交互或完整联机牌局验收。26.3.24 的历史功能、24 组 Java 与 10 项 Node 回归及当时的部署验证，保留于 [26.3.24 说明](riichi-mahjong-fabric/docs/26.3.24.md)。

本版手牌和配对麻将交互体积按可见模型边界生成；自摸与荣和的和牌张放在最右侧，与其余手牌相隔三分之一牌宽。四麻全部难度及三麻 BOT 每次决策随机等待 0.5–1.5 秒。点空不默认弃牌或跳过，桌主可在菜单中二次确认重置牌桌。保留 26.3.23 的完整功能，详见 [26.3.24 说明](riichi-mahjong-fabric/docs/26.3.24.md)。

## 下载与安装

前往 [26.3.26 Release](https://github.com/StealthFeather/riichi-mahjong-fabric/releases/tag/v0.4.2%2Bfabric.26.3.26) 下载：

- `riichi-mahjong-0.4.2+fabric.26.3.26.jar`：放入服务端 `mods/`，同时安装对应 Fabric API。Polymer 已内嵌。
- `TimoryResource-26.3.zip`：沿用 26.3.19 的完整配套包，保留高清物品图标和其他模组资产。本次更新无需更换既有资源包；首次安装可使用此附件。桌面、底座、牌背、牌面和桌边材质保持不变。
- Release 下方的 `Source code (zip/tar.gz)`：GitHub 按发布标签生成的完整仓库源码，含移植代码及固定版本的上游快照。
- `verification.json`：本版构建哈希与 Java、Node 回归结果；`replay-database-verification.json` 记录独立数据库检查结果。`release.json` 记录发布和部署检查的实际执行范围，不代替客户端验收。
- `SHA256SUMS.txt`：发布附件校验值。

请在停服并备份存档后安装，确保运行服务端的账号可以执行 Node.js 22+。客户端无需安装此 Mod 或 Node.js。可选的 Team Reborn Energy API 用于役发电机能源互联。

## 操作

管理员使用 `/mahjong give` 获取物品，`/mahjong` 查看操作。放置麻将桌后右键桌边或座位文字入座，也可使用 `/mahjong join`；桌主潜行右键中心风盘打开菜单，再点击“开始对局”；四麻空位由所选难度的电将 AI 补齐，三麻仍使用原项目 BOT。已入座玩家在结算动画完成后普通右键中心风盘进入下一把。

右键自己的单张手牌出牌。吃、碰、杠、立直、荣和、自摸等通过经验条上方提示和本人面前的按钮执行，相邻按钮留出 3 个字符宽的间距；过期操作自动移除，不再写入聊天历史。立直选中后绿色箭头标记合法弃牌。点击荣和或自摸直接声明；选择跳过可和牌机会（含抢杠）时，先显示“确认跳过”和“返回”，确认后才放弃。只有吃碰杠机会时，普通跳过仍单击。主动离座只使用 `/mahjong leave`，桌子和座位点击不再离座。离开后 BOT 暂代，普通右键桌子或 `/mahjong join` 可接回原座位，保留当前手牌、分数与轮次，原座位不会被其他玩家占用。仅桌主可潜行右键中心风盘或使用 `/mahjong menu` 打开设置（`/mahjong start` 同样进入菜单），支持雀魂、天凤、WRC 四麻及三麻预设。无主牌桌由首次打开菜单的有效玩家认领桌主，命令不会替换已有桌主。整场终盘后在菜单确认结束旧对局，再点击开始新对局。

桌主可在设置中选择“用 AI 取代”接替离线占座者或解除离线原座保留，保持当前手牌、分数、供托和已经接受的鸣牌决定；已由机器人操作的座位继续使用当前机器人。目标必须在整个服务器中离线，其他维度的在线玩家不会被替换。替换后原玩家不再保留专属原座，回来后可按普通入座规则选择可用座位。

菜单“结束对局”与“重置牌桌”共用二次确认页：结束保留当前入座者，重置释放全部座位；取消返回设置，点空或关闭不执行，旧对局或换主后的菜单不能继续确认。

桌主离线时，近旁非旁观玩家可潜行、主手右键真实中心风盘接管权限，并在同一次点击打开菜单，无需先入座；不会同时开局、推进下一手或结束对局。桌主在线时不能接管，原桌主重新上线也不会自动夺回权限。桌主身份独立保存，离座或被 AI 替换不会意外转移。

牌桌显示与碰撞为以中心方块正中为中心的 3×3。本人操作按钮平放在桌沿，点击范围与字体背景一致。缩小后的立直棒位于中央风盘上方。摸牌放在右手边，与其他牌空出 1/3 牌宽；出牌后保留原牌位的空槽，其余牌保持原位，10 tick（正常 20 TPS 下约 0.5 秒）后再合并理牌。流局结算公开所有听牌玩家的手牌，未听牌玩家默认仍保持暗牌。和牌、流局结算及整场对局结束后，尚未公开手牌的玩家可点击本人桌沿的“展示手牌”，主动向桌旁玩家公开自己的手牌与宝牌光效；选择随当前手牌存档保存，下一手或重置时清除。未公开玩家的手牌与光效继续隐藏。

实际宝牌及赤宝牌显示原版附魔光效，覆盖本人的暗手、公开弃牌、副露和结果摊牌。宝牌根据已翻开的指示牌计算，开杠后自动更新；里宝牌仅在立直赢家结算公开里指示牌后参与高亮。暗手的牌面和光效只发送给本人，他人及旁观者看到的暗手、牌墙和暗杠外侧均为无光效牌背。

风牌按钮显示“东、南、西、北”，替代“1风、2风、3风、4风”。三元牌按钮显示“中”“发”“白”，替代原有“3元”“2元”“1元”。成功弃牌播放 `minecraft:block.stone.place`，使用 `ambient` 类别、音量 1、音调 2。吃播放 `minecraft:entity.player.burp`，碰播放 `minecraft:block.end_portal_frame.fill`，明杠、暗杠和加杠播放 `minecraft:block.anvil.place`；四家立直统一播放 `minecraft:item.goat_horn.sound.2`，宣言牌打出时仅播放一次。鸣牌响应期间隐藏公共“等待鸣牌响应”提示，个人操作按钮正常显示。

`26.3.10` 修复本人手牌与公共牌背重叠造成的闪烁，包含最右侧普通手牌。手牌所属玩家变化或流局公开时，显示实体也会按新的可见范围重建。

桌上显示随庄家轮转的门风、当前出牌者；场次、分数、余牌及结算移至本人 BossBar。鸣牌按出牌者相对方位横放，加杠叠放；暗杠左右两张牌背朝上，中间两张显示牌面。立直宣言牌被吃、碰或杠拿走后，其横放标记顺延到其后第一张仍在牌河内的弃牌；后继牌再被鸣走时继续顺延，弃牌记录及赤牌身份保持不变。普通荒牌流局结算按规则预设及听牌人数计算未听罚符。荒牌流局时庄家听牌连庄，庄家未听换庄；途中流局始终连庄。所有流局本场加一，庄家和牌连庄且本场加一，闲家和牌本场归零。每桌一个隐身、NoAI 的虚拟潜影贝承担原版客户端碰撞；服务端玩家使用相同包围盒。完整牌局留在服务端，对局中的暗牌牌面只发送给所属玩家。

拆除麻将桌的全部九个部件均要求主手持 `minecraft:pickaxes` 标签中的任意镐，副手镐不算，不要求工具等级，创造和生存模式同样适用。未持镐时阻止破坏并显示限频提示“需要主手持镐才能拆除麻将桌”；普通挖掘及攻击虚拟碰撞实体的直接破坏入口均受检查。单人配对麻将等其他方块保持原行为。

同时包含牌谱、预设练习牌谱、单人配对麻将、麻将祭坛、役发电机、自动点击器、物品、配方和进度。53 个麻将进度的标题与达成说明已汉化。

## 牌谱回放与分析

完整对局自然结束后自动归档，手动结束或重置的未完成对局不保存为完整牌谱。主手右键“牌谱”物品打开玩家概况，进入“我的牌谱”：日历中有参与记录的日期显示红中，其他日期显示白板。点击红中日期查看当天按结束时间从新到旧排列的对局，发财切换分析开关；点击该行第一个物品，将记录载入 8 格内自己拥有、无进行中对局且无其他真人在座的牌桌。牌谱物品不再保存桌面配置，预设练习牌谱仍可使用。

回放控件跟随所选视角，集中在牌河左右两列。“上一步／下一步”按动作帧移动，“上一巡／下一巡”跳到所选视角玩家的相邻出牌回合，同一巡中的杠、拔北及补牌不重复计巡。支持上下局、首尾、播放／暂停、倍速、切换视角与全部手牌显示；桌沿列出当时合法的鸣牌、立直及和牌等操作，仅供查看，不会执行历史动作。

分析复用现有麻将 AI 的评估建立 softmax 策略分布，**不是 AI 原生概率，也不是胜率**。全部合法弃牌牌种与全部合法操作分别独立归一，完整分布的整数分数各自合计 100，单选可显示 100。候选按34种牌归并，赤五与普通五共用分数；手牌只显示概率前三且整数分数至少1的牌种，每种只显示一个纯数字分数，历史实际选择仅显示一个箭头：最大概率为绿、第二或第三为黄、其他为红；标记从该次手牌选择跟随到准确的河牌或被鸣走的副露。本局一致性评分按各次出牌相对最优概率的比值评分后取平均，最优为100；整场评分按整场所有出牌取平均，只显示在牌谱列表玩家物品说明中。

读取并复用 `config/timory_quest_server.json` 的 MySQL 连接设置及时区，使用麻将专用的 `riichi_replays`、`riichi_replay_players`、`riichi_replay_analysis` 表，不改动 Quest 配置及业务表。已有牌谱继续可读；旧分析缓存失效后按版本3重算。写库故障时完整记录先保留到世界目录 `data/riichi-replay-outbox/`，恢复后补传。备份时同时保留世界及数据库。

普通宝牌和赤五继续使用原版附魔光效；客户端光影或渲染设置可能影响其显示。本版修复规则进入终盘后丢失最后结算展示、导致已公开里宝牌不再高亮的问题，不更换材质或增加附魔替代方案。详细操作、概率模型、兼容与验证范围见 [26.3.26 说明](riichi-mahjong-fabric/docs/26.3.26.md)。

## 构建与限制

详见 [移植说明](riichi-mahjong-fabric/PORTING.md) 和 [构建环境说明](BUILDING.md)。仓库提供完整源码；现有构建脚本仍使用 Timory 工作区准备的 Minecraft、Java 与 Polymer 依赖目录，未提供独立下载依赖的一键构建流程。

原版客户端界面由显示实体、interaction、ActionBar 提示和原版容器替代。客户端 FOV 调整、渲染编辑器等不能直接移植；自定义流体以水投影，单个潜影贝的桌下碰撞为近似。

`26.3.13` 通过 9 组主回归、9 项通用服务器集成检查及 8 项实际桌实体交互检查。原版客户端验证普通和密集缩放按钮布局各 3 次文本采样、7 个声音数据包窗口，并实际操作自摸“跳过→返回→跳过→确认”流程；截图已复核。以上为固定场景测试，未遍历整场多人牌局。测试机 OpenAL 音频设备不可用，声音只核对数据包参数，未验收扬声器播放效果。详见 [26.3.13 变更与验证](riichi-mahjong-fabric/docs/26.3.13.md)。此前验证保留在 [26.3.12 说明](riichi-mahjong-fabric/docs/26.3.12.md)。
