# Timory Mahjong

Timory Mahjong 0.5.3-beta.1 是 Minecraft 26.3 Fabric 服务端麻将模组。玩家使用原版客户端并接受 TimoryResource 资源包。

支持雀魂、天凤、WRC、川麻、公式战和 M-League，可选择东风场或南风场。换三张、赖子和血战到底可独立开启。玩家可在牌桌菜单入座、观战和调整对局设置，输入 `/mahjong stats` 查看个人对局统计。

按住 Shift 右键中心风盘，点击“我的出牌方式”，可在右键直接出牌和二次确认之间切换。日麻吃、碰后和川麻碰后，暗杠或加杠须等自己再次摸牌。

使用牌谱物品可查看已完成的对局记录、回放牌局及分析。对局统计和回放按玩家权限显示；公式战积分暂不设升段。

请到 [GitHub Releases](https://github.com/StealthFeather/riichi-mahjong-fabric/releases) 下载服务端 JAR 和资源包。服务端需要 Minecraft 26.3、Fabric API、Java 25 及 Node.js 22+；玩家无需安装客户端 Mod。

详细规则、统计、构建和许可信息见 [项目说明](riichi-mahjong-fabric/README.md)、[0.5.3-beta.1 更新说明](riichi-mahjong-fabric/docs/0.5.3-beta.1.md) 和 [构建说明](riichi-mahjong-fabric/BUILDING.md)。
